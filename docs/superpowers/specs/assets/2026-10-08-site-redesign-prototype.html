Paper and Ink, with Motion off

Turn Motion off (bottom right): the voile drifts away over a second and leaves plain paper, or slate in Ink, with a fine still grain, like Lefos with its shadows off. Hovers become a flat tinted block behind the label, appearing in a tenth of a second; the current chapter keeps its block. Turn Motion back on and the cloth and the ink return. People whose system asks for reduced motion land on the still page and never load the cloth. Starts in Ink; the switch beside Motion cycles Ink, Auto, Paper.

A quiet place for what your agents make.

Agents make things all day: a screenshot from a failing test, a bundle of logs, a report written in the middle of the night. Most of it needs to be seen by one or two people, for a little while.

Veilfile gives each file a private link, and lets it go when its time is up. No public repository, no bucket to lock down, no paste that lives forever.

The life of a file

Made.
Your agent pushes a file through the command line, the API, or MCP.
Veiled.
It gets back an unguessable link. The 256-bit token in the address is the only key; nothing is listed or indexed.
Seen.
You share the link with whoever should see it. Uploads are checked for anything shaped like a secret, and flagged.
Let go.
When its days run out, the link stops working and the file is deleted. Nothing to clean up.

Begin

$ npm install -g veilfile  or: pip install veilfile
$ veilfile login  approve in your browser
$ veilfile push report.pdf  prints a private link

For agents that speak MCP, the server is at veilfile.com/mcp. Everything else is in the docs.

What we promise

The link is the only way in.
No listings, no search, no addresses anyone could guess.
Gone means deleted.
When a file expires it is removed from storage, not hidden.
We look for secrets, not at your files.
Uploads are scanned for the shapes of keys and tokens; their contents are never logged.
Why not a gist?
A gist is public by default and lives forever. Fine for a snippet; wrong for a client's failing screenshot. See how a file lives here.

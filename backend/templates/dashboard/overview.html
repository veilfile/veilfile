Get connected

The recommended way to connect is the CLI. Install it with pip install veilfile, run veilfile login, open the page it prints, and enter the code there. The key is stored in a credentials file only you can read. The CLI prints it only if you pass --print-key, and it does not write it to your shell history. Then run veilfile push screenshot.png. Your upload appears under Files.

{% include "components/code_block.html" with id="onboarding-pip" label="Copy the pip install command" code="pip install veilfile" only %} {% include "components/code_block.html" with id="onboarding-login" label="Copy the veilfile login command" code="veilfile login" only %} {% include "components/code_block.html" with id="onboarding-push" label="Copy the veilfile push example" code="veilfile push screenshot.png" only %}

The code expires after ten minutes. Approving a login needs a verified email. If yours is not verified yet, verify it, then run veilfile login again.

Headless machine, or a restricted shell where the browser flow cannot run? Create a key on the Keys page, copy the one-time value, and export it where your agent runs. Keep this path for headless machines and restricted shells only. A key you copy by hand can end up in shell history, which is why the recommended login above is the guide to follow.

Each login mints one API key, and device-issued keys count toward your plan's key cap (one key on Free). The full three-step walkthrough is in the quickstart.

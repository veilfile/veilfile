The life of a file

Made
Your agent pushes a file through the command line, the API, or MCP.
Veiled
It gets back an unguessable link. The 256-bit token in the address is the only key. There is no public list of files, and nothing is indexed.
Seen
Share the link with whoever should see it. Veilfile scans the first 1 MiB of each upload for known secret formats, such as API keys and tokens, and flags any match.
Let go
When its days run out, the link stops working at once, and the file is deleted from storage soon after.

The technical version is in the Docs: how it works, in full.

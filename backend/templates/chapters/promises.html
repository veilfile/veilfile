What we promise

The link is the only way in
Nothing is listed publicly, links ask search engines not to index them, and no one can guess an address.
Gone means deleted
When a file expires its link stops working, and a sweep removes the file from storage, usually within a day. It is not hidden; it is gone.
We flag secret-shaped text and never log contents
Veilfile scans the first 1 MiB of each upload for known key and token formats, and flags a match by name. Unless you ask for rejection, a flagged upload is still stored. File contents are never logged.
Why shouldn’t I use a gist?
A gist stays until someone remembers to delete it, and it keeps every earlier version. A gist suits a snippet but not a client’s failing screenshot. See how a file lives here.

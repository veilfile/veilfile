What we promise

The link is the only way in.
No public list, nothing indexed, no addresses anyone could guess.
Gone means deleted.
When a file expires its link stops working, and a sweep removes the file from storage, usually within a day. It is not hidden; it is gone.
We look only for the shapes of secrets.
Uploads are scanned for anything shaped like a key or a token, and a match is flagged by name. File contents are never logged.
Why not a gist?
A gist stays until someone remembers to delete it, and it keeps every earlier version. Fine for a snippet; wrong for a client’s failing screenshot. See how a file lives here.

Approving creates an API key for your workspace. Whoever holds the key can do these things:

  • Upload files and create share links
  • List every artifact in the workspace and download each one through its link
  • Revoke artifacts
  • List the workspace's API keys and revoke only the key in use
  • See the account email and plan usage

It cannot create other API keys, disconnect your apps, or change your billing or account settings. The key does not expire: it works until you revoke it in the dashboard. {% if key_cap %}It counts toward your plan's limit of {{ key_cap }} API key{{ key_cap|pluralize }}.{% endif %} It is sent only to the terminal; this browser never sees it.

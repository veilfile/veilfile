Veilfile is private, expiring artifact hosting for AI agents. An agent uploads a file (a screenshot, a log bundle, a HAR) and gets back an unguessable link that stops working on its own. There is no public bucket to configure and nothing to clean up.

If you are an agent, skip the tour: [llms.txt](/llms.txt) is the machine-readable manual.

If you're new here, start with the [Quickstart](/docs/quickstart/).

| You want to... | Go to... |
|---|---|
| Upload your first file from the terminal | [Quickstart](/docs/quickstart/) |
| Connect an agent via MCP | [Agent setup](/docs/agent/) |
| Call the API directly | [API reference](/docs/api/) |
| Understand TTLs, limits, and plans | [How it works](/docs/how-it-works/) |

The full technical reference is [API.md](https://github.com/veilfile/veilfile/blob/main/docs/API.md).

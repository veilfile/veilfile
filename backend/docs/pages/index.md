Veilfile is private, expiring artifact hosting for AI agents. An agent uploads a file (a screenshot, a log bundle, a HAR) and gets back an unguessable link that stops working on its own. No public bucket to configure. Nothing to clean up.

If you are an agent, skip the tour: [llms.txt](/llms.txt) is the machine-readable manual.

New here? Start with the [Quickstart](/docs/quickstart/).
